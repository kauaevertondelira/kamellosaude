# Kamello demonstração web

Arquivos compilados para apresentar e testar a interface do projeto Kamello. Dados fictícios são mantidos apenas no navegador; a demonstração não utiliza o banco de produção, não envia e-mail nem sincroniza entre aparelhos. Não inserir dados reais. A prévia não é serviço clínico nem SaaS em operação comercial.

Publicado em https://kauaevertondelira.github.io/kamellosaude/ pelo workflow GitHub Pages, a cada atualização de main. Não precisa instalar dependências para acessar o site.

Contas fictícias: participante@kamello.demo e admin@kamello.demo, senha de demonstração KamelloDemo!2026. Os botões de demonstração preenchem os campos.

Interface baseada na marca Kamello, com Motion, GSAP, Anime.js e Swup. Health+ e Roczen foram usados somente como referência de layout; nenhuma foto/vídeo/conteúdo desses sites foi copiado.

O código completo do servidor e do Android, as regras e os documentos de implantação são entregues ao responsável separadamente para o repositório privado da contratante. A produção usa Firebase Authentication, Realtime Database e a API HTTPS. O GitHub Pages hospeda aqui apenas a demonstração, conforme suas restrições de uso.
